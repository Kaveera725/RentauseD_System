# RentauseD Copilot Request Messages

Use these prompts in Copilot Chat to extend or modify the project.

## Feature prompts
- Add a booking conflict check to prevent overlapping rentals.
- Add an owner dashboard that lists each item with its booking history.
- Add admin ability to deactivate a user account.
- Add a calendar view for upcoming bookings.
- Add email notifications using a local SMTP test server.

## Quality prompts
- Review server-side validation gaps in the booking flow.
- Add tests for the auth and item approval endpoints.
- Improve error messages for file upload failures.
- Add rate limiting to prevent brute force logins.

## UI prompts
- Add a dark accent variant for the hero section.
- Add a detail page for each listing.
- Add sorting options to the listing feed.
